# 问题分型

分型只用于生成候选模型族，不直接替用户选择模型。综合题允许每个子问题分别标注多个类型。
几何/路径、随机风险、信号/反演等场景标签可与五类叠加；完成主类型核对后，建议扫描“选型前必须核对”列中的适用场景加查项，不把加查项所在行理解为固定归属。

| 类型 | 识别信号 | 候选模型族 | 选型前必须核对 |
|---|---|---|---|
| 评价 | 排序、打分、优选、综合指标 | 标准化与加权、PCA/因子分析、熵权、TOPSIS、AHP、模糊评价 | 指标方向、量纲、权重来源、AHP 一致性、排序稳定性 |
| 优化 | 最大/最小、调度、路径、配置、方案设计 | 线性/整数/非线性规划、动态规划、网络流、启发式与元启发式 | 决策变量、目标、硬约束、可行性回代、最优性或下界证据；几何/路径场景建议加查坐标系、可达与覆盖/碰撞、连通与速度连续、误差传播 |
| 预测 | 时间趋势、分类、回归、未来状态 | 回归、时间序列、状态空间、树模型、神经网络 | 时间切分、数据泄漏、基线、误差指标、不确定性；信号/反演场景建议加查采样率、分辨率、噪声、边界、可辨识性和正则化 |
| 机理 | 解释演化、传播、作用机制、物理过程 | 微分/差分方程、守恒模型、概率过程、系统动力学、仿真 | 状态变量、参数可辨识性、边界/初值、量纲、极端情形；随机风险场景建议加查分布依据、样本量、置信水平、变量依赖、风险预算和最坏情形 |
| 综合 | 多阶段或多类型耦合 | 分层建模、评价→优化、预测→决策、机理→校准 | 子模型接口、误差传播、共享变量、阶段依赖和统一口径 |

## 路由步骤

1. 从题面逐问提取动词、对象、输入、约束和显式交付物。
2. 用 `data_profile.md` 核对样本量、字段类型、缺失、异常、时间/空间结构。
3. 为每个子问题写主类型和次类型，不确定时列出歧义及所需证据。
4. 只保留能用现有数据实现、能在竞赛时间内验证、能回答显式交付物的 2–3 条路线。
5. 比较任务匹配、数据匹配、实现成本、验证负担、解释性和失败风险。
6. 向用户给出推荐与拒绝理由；用户可改选候选或指定候选之外的路线，指定路线按同一框架补评估后照办并留痕；确认前不进入正式建模。

## 常见误路由

- 只有排序需求却直接使用预测模型；
- 用复杂模型替代缺失的目标函数或约束；
- 对时序数据随机划分训练/测试集；
- 在全量数据上拟合预处理或特征选择造成泄漏，或只报单一准确率而不分析误差结构；
- 把相关性写成因果机理；
- 未建立守恒、动力学等机理关系就套优化算法，或只给轨迹而不检查边界与终端状态；
- 在有负权边的图上使用 Dijkstra；
- 路径或选址模型漏掉连通、容量、子回路或边界约束；
- 几何或路径模型的坐标定义与图示不一致，或只报最短距离而不给完整路线与时序；
- 经营、供应链或调度模型只追求单一收益而遗漏服务与风险，或只报总目标值而不给可执行安排；
- 随机风险模型随意指定分布和扰动范围，或只报期望最优而不检查失效概率；
- 信号或反演过程只列算法、展示结果图，却不报告重建误差、噪声影响或信息损失；
- 用同一评价权重同时充当优化目标且不解释来源。

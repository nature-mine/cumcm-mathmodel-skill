# 建模检查清单

在建模件提交评审前逐项检查。清单不能替代题意推导；不适用项应说明原因。

## 通用完整性

- [ ] 子问题的目标、输入、输出与题面逐项对应，没有悄悄改题。
- [ ] 题面事实、数据观察、假设和结论分开陈述。
- [ ] 假设均有稳定编号、依据、适用范围、失效影响和验证方式。
- [ ] 符号含义唯一，维度、单位、取值域和来源齐全。
- [ ] 公式量纲一致，边界条件和初始条件明确。
- [ ] 模型参数可由题面、附件、核实来源或明确的估计步骤得到。
- [ ] 关键结论有验证方案，主模型有灵敏度或稳健性实验。
- [ ] 样本筛选、缺失剔除和各统计量分母明确；不同问或不同指标样本量不同时说明差异来源。
- [ ] 灵敏度结论不超出实际运行场景，且能指向结果文件；小样本经验高分位阈值说明不稳定性或给出扰动结果。
- [ ] 使用置换负对照时默认不少于 1000 次并披露实际次数；降低次数必须说明依据与精度影响。
- [ ] 编程接口固定字段、单位、精度、随机性、输出口径和失败路径。
- [ ] 已注明基线、候选路线、选择权衡和模型失效条件。
- [ ] 方法出处只登记引用需求，没有凭记忆生成文献条目。

## 评价类

- [ ] 指标方向、量纲处理、归一化和缺失处理有依据。
- [ ] 权重来源可解释；主观权重与客观权重不混写。
- [ ] 使用 AHP 时检查判断矩阵互反性和一致性比率，不一致则返工。
- [ ] 排名对权重扰动、归一化方式和异常值不敏感，或已披露敏感区间。
- [ ] 综合得分可回溯到原始指标，不把相关指标重复计权。

## 优化类

- [ ] 决策变量、目标、硬约束、软约束和可行域分别定义。
- [ ] 容量、守恒、时序、整数性、边界和逻辑联动约束没有遗漏。
- [ ] 路径/调度模型已防子回路；几何装箱已检查 OBB 与 SAT 等真实碰撞条件。
- [ ] 求解器返回值之外，候选解逐条回代所有约束。
- [ ] 报告最优性缺口、停止条件、不可行处理和规模上升时的复杂度风险。

## 预测类

- [ ] 训练、验证、测试划分尊重时间或实体边界，没有数据泄漏。
- [ ] 预处理、特征选择和调参只在训练信息内拟合。
- [ ] 与朴素基线比较，并使用与题目目标一致的指标。
- [ ] 说明外推范围、误差分布和不确定性；不只报告单一平均指标。
- [ ] 时间序列滚动验证没有把未来信息用于过去预测。

## 图与网络类

- [ ] 明确有向/无向、权重含义、连通性和节点/边约束。
- [ ] 存在负权边时不使用 Dijkstra；若有负环，单独说明处理。
- [ ] 最短路、最大流、选址或网络鲁棒性指标与题目决策相匹配。
- [ ] 网络规模、稀疏性和不可达节点的处理进入实现接口。

## 机理与动态系统

- [ ] 守恒关系、状态变量、时间尺度、初边值条件和参数单位一致。
- [ ] 稳态近似、线性化或独立性假设有适用范围。
- [ ] 参数可辨识性得到检查，拟合好不等于机制已被验证。
- [ ] 用极端情况、守恒残差或已知特例验证数值解。

## 提交前红线

出现任一情况不得返回 `ready_for_review`：

- 关键题意仍有两种实质不同的解释；
- 公式或单位自相矛盾；
- 依赖未冻结却继续推导；
- 参数来源不明并被填入具体数值；
- 仅给方法名称，没有可实现公式或接口；
- 用“结果应该很好”代替可执行验证。
